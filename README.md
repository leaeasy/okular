## 1. 关闭最后一个标签页时关闭窗口

补丁：[0001-quit-app-when-last-tab-close.patch](0001-quit-app-when-last-tab-close.patch)

修改 `shell/shell.cpp` 中的 `Shell::closeTab()`：成功关闭最后一个标签页后，调用 `close()` 关闭当前窗口，替代原来的显示欢迎页面。

这使单窗口阅读时可以通过关闭最后一个标签页直接退出；如果还有其他 Okular 窗口，本补丁并不会强制退出所有窗口。

## 2. 限制页面图像缓存并清理过期缓存

补丁：[0002-limit-normal-and-aggressive-memory-cache.patch](0002-limit-normal-and-aggressive-memory-cache.patch)

修改 `core/document.cpp`、`core/document_p.h` 和 `core/page.cpp`，为页面图像（Pixmap）缓存增加容量限制和基于最近访问时间的过期回收，减少长时间阅读时闲置缓存的占用。

| 内存策略 | 本补丁增加的容量限制 | 缓存闲置过期时间 |
| --- | --- | --- |
| Low（低） | 未增加新的容量限制 | 不启用本补丁的过期清理 |
| Normal（普通） | 总物理内存的三分之一与 2 GiB 中的较小值 | 60 秒 |
| Aggressive（积极） | 4 GiB | 10 分钟 |
| Greedy（贪婪） | 未增加新的容量限制 | 30 分钟 |

缓存创建时记录时间，命中缓存时更新最近访问时间。定时内存检查会清除超过闲置时间的图像，但保留当前视口页和当前可见页，避免正在阅读的页面因过期而被回收。原有根据可用内存释放缓存的逻辑仍然保留。

这里的容量限制是页面图像缓存的回收目标，不是 Okular 进程总内存的硬上限；缓存回收后，再次访问相应页面可能需要重新渲染。

## 3. 增加 Florilegium 风格植物水印

补丁：[0001-add-florilegium.patch](0001-add-florilegium.patch)

新增 `okular_floral` 页面装饰插件，并接入页面绘制、配置界面和“视图”菜单。设计借鉴 Florilegium 的植物生成思路，使用 C++ 和 Qt 路径程序化绘制，不依赖 Lua、外部图片或 Florilegium 运行时。

### 使用方式

在“配置 Okular”中的 `Plants`（植物）页面启用植物水印。该功能默认关闭，可设置以下参数：

| 参数 | 默认值 | 可选范围或说明 |
| --- | --- | --- |
| 画风 | 水彩 | 水彩、墨线轮廓、剪影 |
| 植物变体 | 0 | 相同变体可恢复相同植物；设置应用于所有书籍 |
| 密度 | 50% | 0～100% |
| 不透明度 | 18% | 5～100% |
| 宽度 | 64 个逻辑像素 | 16～160 个逻辑像素 |
| 颜色 | `#2456C4` | 可自定义，默认 Delft 蓝 |

配置页的 `New plants` 按钮和“视图”菜单的 `New Plants` 操作可切换并保存植物变体。

### 显示效果与生成规则

- 植物从页面左下角沿左侧和底部生长，叠加在页面内容上，不额外占用页边距，也不改变页面缩放、裁剪或双页布局。
- 根据文档 URL、页码和保存的变体生成稳定种子；相同输入下重绘会保持图案稳定，文档路径或变体变化可能改变植物。
- 每本文档固定选取四个物种：三个在左侧混生，第四个用于底部侧枝。植物随页面阅读进度出现叶片、花苞和花朵；较长文档后期还会表现老化。
- 底部侧枝在进度达到 10% 后出现，并随进度增加分叉和花叶。
- 绘制时避开批注和表单区域；浅色页面采用 Multiply 混合，深色页面采用 Screen 混合，彩色正文可能受到水印染色。

### 性能与集成

宿主仅处理当前页及前后各两页范围内的可见区域。插件使用约 8 MiB 的矢量 LRU 缓存和约 32 MiB 的栅格 LRU 缓存，以减少重复生成和绘制开销。

插件随桌面版本构建，安装到 Qt 插件目录下的 `okular6/decorations`。宿主动态加载插件；插件缺失时继续正常显示文档。宿主和插件使用私有接口，修改接口后需要同步重新编译。
